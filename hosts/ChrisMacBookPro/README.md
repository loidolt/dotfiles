# ChrisMacBookPro Host Configuration

This directory contains host-specific configuration for ChrisMacBookPro.

## Files

- `host.sh` - Host-specific shell configuration, sourced by .zshrc
- `ssh-config` - Host-specific SSH configuration, copied to ~/.ssh/config.local

## Setup

Run the host.sh script to install host-specific configurations:

```bash
bash hosts/ChrisMacBookPro/host.sh
```
