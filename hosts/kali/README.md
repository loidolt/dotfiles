# kali

Kali GNU/Linux Rolling workstation.

## Setup Notes

- Uses Linuxbrew for package management (installed at `/home/linuxbrew/.linuxbrew`)
- ZSH from Homebrew

## Host-specific Configuration

- `host.sh` - Shell configuration sourced by `.zshrc`
- `ssh-config` - SSH configuration (optional, copied to `~/.ssh/config.local`)
